## Overview

Welcome to my Azure Cloud Security Portfolio.

This repository documents my hands-on journey in designing, implementing, securing, and documenting enterprise-grade Azure cloud environments.

Each project focuses on practical cloud security scenarios and follows Microsoft security best practices.

The goal of this portfolio is to develop practical skills for Cloud Security Engineer and Cloud Security Architect roles.

---

## Learning Objectives

- Design secure Azure cloud infrastructure
- Implement Microsoft cloud security services
- Apply Zero Trust security principles
- Gain hands-on cloud security experience
- Build enterprise-level security documentation
- Develop a professional cloud security portfolio
