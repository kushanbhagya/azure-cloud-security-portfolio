# Azure Cloud Security Portfolio

## Overview

Welcome to my Azure Cloud Security Portfolio.

This repository documents my hands-on journey in designing, implementing, securing, and documenting enterprise-grade Azure cloud environments. Each project is built using Microsoft security best practices and focuses on practical, real-world cloud security scenarios.

The primary goal of this portfolio is to strengthen my Azure security knowledge while preparing for Cloud Security Engineer and Cloud Security Architect roles.

---

## Learning Objectives

- Design secure Azure infrastructure
- Implement Microsoft security services
- Apply Zero Trust security principles
- Gain practical experience with cloud security
- Build enterprise-level documentation
- Develop a professional GitHub portfolio
